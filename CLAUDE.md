## Project Overview

This is a static site for Metropoliplan built with [Astro 4](https://astro.build/) and [i18next](https://www.i18next.com/) for internationalization. The site supports three languages: German (de), Spanish (es), and English (en), with German as the default.

## Architecture

### Language & Routing

- **Astro's i18n routing**: Configured in `astro.config.mjs` with locales `['de', 'es', 'en']` and default locale `'de'`
- **Page structure**: Language-specific content lives in `src/pages/[lang]/` directories (e.g., `src/pages/en/faq.adoc`, `src/pages/es/about.adoc`)
- **Dynamic routing**: The `src/pages/[lang]/index.astro` file uses Astro's dynamic route parameters to serve locale-specific content
- **Language switching**: Use `getRelativeLocaleUrl(locale, 'page-path')` helper from `astro:i18n` to generate locale-aware links

### Internationalization (i18n)

- **Translation files**: Located in `src/translations/` as JSON files (`en.json`, `de.json`, `es.json`)
- **i18n initialization**: `src/i18n.ts` exports `initI18n(lng)` which sets up i18next and returns the translation function `t`
- **Usage in components**: Import `initI18n`, call it with `Astro.props.locale`, then use `t('key')` to get translated strings
- Example from Home.astro: `const t = initI18n(Astro.props.locale); t('description')`

### Components & Layouts

- **Main layout**: `src/layouts/Layout.astro` wraps pages with common HTML structure
- **Legal layout**: `src/layouts/Legal.astro` used for privacy and legal pages
- **Home page**: `src/components/Home.astro` renders the index with Cards linking to FAQ, documentation, and status
- **Card component**: `src/components/Card.astro` is a reusable link card with icon, title, and body
- **Logo**: `src/components/MepLogo.astro` renders the Metropoliplan logo

### Content

- **AsciiDoc pages**: `.adoc` files in `src/pages/` and language subdirectories are automatically converted to HTML routes
- **Frontmatter**: Pages use YAML frontmatter to specify layout and title (e.g., `layout: ../../layouts/Legal.astro`)
- **Main pages**: FAQ (`faq.adoc`), About (`about.adoc`), Privacy Policy (`privacy.adoc`) exist in language-specific directories

## Key Implementation Details

- **Locale passing**: The root `index.astro` passes `locale={Astro.currentLocale!}` to the Home component
- **External links**: Documentation link uses a hardcoded pattern `/index-{locale}.html` (external resource, not generated by this site)
- **Status link**: Points to an external status page at `https://www.metropoliplan.org/MEP-Status/`
